class KeyScorer:
    def score(self, key: ApiKey) -> float:
        return (
            key.quota_score()
            + key.idle_score()
            - key.error_penalty()
        )

## ✅ 核心逻辑

### allocate_key.py

```python
class AllocateKeyQuery:
    async def execute(self, provider: str):
        keys = await repo.get_available_keys(provider)
        key = scheduler.select_key(keys)
        await repo.mark_used(key)
        return key
```
